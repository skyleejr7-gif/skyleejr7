# 국민기초생활수급자·차상위계층·한부모가족·기초연금·장애인복지 판정 프로그램

소득·재산·금융재산·자동차·부양의무자 정보를 입력하면 **소득인정액**을 계산하고,
생계·의료·주거·교육급여(국민기초생활수급자), 차상위계층 세부사업, 한부모가족(일반/청소년),
자산형성지원사업, 기초연금, 장애인연금·장애수당·장애아동수당 선정기준 충족 여부를 판정하는
웹 기반 계산기입니다.

## 사용 방법

별도 설치나 서버 없이, `index.html` 파일을 웹 브라우저(Chrome, Edge 등)로 열기만 하면 됩니다.

```
index.html 더블클릭 → 브라우저에서 실행
```

## 주요 기능

- **금액 입력란 천단위 콤마 표시**: 모든 금액(원) 입력란은 입력하는 즉시 1,000단위마다 콤마가
  자동으로 표시되어 큰 금액도 읽기 쉽습니다(계산에는 콤마를 제외한 숫자만 사용)
- **적용 연도 선택**: 2026년(현행) / 2027년(2026.7.28. 제80차 중앙생활보장위원회 의결,
  2027.1.1. 시행) 기준 중위소득을 전환하며 판정
- **가구 정보**: 가구원 수, 거주 지역(서울/경기/광역·세종·창원/그 외)에 따른 기본재산액·
  주거용재산 한도액 자동 반영(한도 초과분은 일반재산으로 산정)
- **소득 산정**: 가구원별 근로·사업소득 + 공제 특례(기본 30%, 34세 이하·대학생, 65세 이상
  노인·등록장애인·북한이탈주민, 35세 이상 초중고생, 직업재활사업 참여소득, 임신부·사회복무요원
  등) 자동 계산. 사업·재산·이전소득, 가구특성별 지출비용(의료비 등) 반영
- **재산의 소득환산액**: 주거용(1.04%)·일반(4.17%)·금융(6.26%) 재산별 환산율, 부채·기본재산액
  순차 차감(주거용→일반→금융), 금융재산 생활준비금 500만원 우선 공제
- **자동차 재산**: 차종(승용/승합·화물/이륜)·배기량·가액·차령·용도별로 재산산정 제외(생업용
  1대, 중증장애인·국가유공자 상이1~3급 이동수단 1대)/완화(4.17%, 노후·저가 차량, 다자녀·거동곤란
  등 특례)/원칙(100%)을 자동 분류하고, 가구별 **보유 한도(제외 1대·완화 1대)** 초과분은 자동으로
  100%로 전환
- **의료급여 부양의무자 판정 (없음·미약·있음 3단계)**: 부양능력 판정소득액·재산의 소득환산액을
  소득기준((A×40%)+(B×100%), 취약계층은 (A+B)×74%와 비교해 더 높은 값)·재산기준((A+B)×18%)과
  비교. '있음'은 즉시 의료급여 제외, '미약'은 부양비(판정소득액이 B×100% 초과분의 10%)를 의료급여
  판정용 소득에만 가산, '없음'은 영향 없음
- **의료급여 부양의무자 완전면제 특례**: 수급(권)자 가구에 노인(65세 이상)·중증(심한)장애인이 있고
  동시에 부양의무자 가구에 기초연금·장애인연금 수급자가 있는 경우, 또는 부양의무자 가구에 20세
  이하 1·2·3급 중복 등록장애인이 있는 경우 그 부양의무자는 기준 자체가 미적용됩니다. 경증(심하지
  않은) 장애인 등 일반 취약계층은 완전면제가 아닌 소득기준 74% 완화만 적용됩니다
- **생계급여 고소득·고재산 부양의무자 예외조항**: 부양의무자 연소득 1억3,000만원 이상 또는
  재산(금융재산 제외) 12억원 이상이면 다른 급여와 무관하게 생계급여만 별도로 제외
- **재산범위 특례**: 근로무능력자로만 구성된 가구가 순재산·금융재산이 특례액 이내이고 월 100%
  환산 자동차가 없으면 재산의 소득환산액을 전액 제외
- **차상위 세부사업 판정**: 차상위계층확인·차상위자활(근로능력자)은 소득인정액 50% 기준만으로
  판정(부양의무자 기준 미적용). **차상위 본인부담경감**(희귀난치성·중증·만성질환자, 18세 미만
  아동)은 소득인정액 50% 기준에 더해 **의료급여와는 별개인 부양의무자 기준**을 적용 —
  의료급여는 소득+재산 결합 3단계(없음·미약·있음) 판정을 쓰지만, 차상위 본인부담경감은
  **부양의무자의 소득만**을 부양의무자 가구 기준 중위소득과 비교(재산·부양비 미반영, 비율은
  설정에서 조정 가능)
- **자산형성지원사업 판정**: 희망저축계좌Ⅰ(생계·의료수급 + 근로소득 ≥ 중위소득 40%의 60%),
  희망저축계좌Ⅱ(주거·교육수급 또는 차상위계층 + 근로소득 있음), 청년내일저축계좌(만 15~34세,
  수급자·차상위는 39세까지 + 근로소득 있음 + 소득인정액 50% 이하)를 가구 근로·사업소득·연령·
  총재산기준과 함께 판정
- **판정표**: 생계급여(32%)·의료급여(40%)·주거급여(48%)·교육급여(50%)·차상위계층(50%)·
  한부모가족/조손가족(63%)·청소년한부모/조손가족 완화기준(65%)을 한 번에 비교
- **기초연금·장애인연금 판정**: 국민기초생활보장과 **별도의 소득인정액 산식**(근로소득 108만원
  정액공제 후 30% 추가공제, 재산의 소득환산율 연 4%, 금융재산 공제 2,000만원, 대도시/중소도시/
  농어촌 3단계 기본재산액, 고급자동차·회원권 가액은 월 100% 그대로 반영, 무료임차소득 반영)을
  사용해 기초연금(단독 247만원/부부 395.2만원)·장애인연금(단독 140만원/부부 224만원) 선정기준액과
  비교. 부양의무자 기준은 적용되지 않음
- **장애수당·장애아동수당 판정**: 별도 소득기준 없이 위에서 판정된 **국민기초생활수급자 또는
  차상위계층 여부**(이른바 "차상위장애인" 포함)에 장애 정도·연령을 결합해 판정. 장애수당은 만
  18세 이상 경증(심하지 않은) 등록장애인, 장애아동수당은 만 18세 미만(또는 18~20세 재학 특례)
  등록장애인이 중증·경증 관계없이 대상이며, 둘 다 장애인연금 수급 중이면 제외
- **기준값 설정**: 기준 중위소득, 선정기준 비율, 지역별 기본재산액·주거용재산 한도액·부양의무자
  기본재산액, 소득환산율, 고소득·고재산 기준액, 재산범위 특례액, 자산형성지원사업 소득·재산·연령
  기준, 기초연금·장애인연금 선정기준액·산식 기준 등을 화면에서 직접 수정 가능 (매년 보건복지부가
  익년도 기준을 새로 고시하므로, 연도가 바뀌면 이 값들만 갱신하면 계속 사용할 수 있습니다)

## 유의사항

이 프로그램은 대표적인 산식을 반영한 **참고·추정용 도구**입니다. 실제 수급자 결정은 부양의무자의
소득·재산 실사, 재산 세부 항목(분양권·조합원입주권 등) 확인, 자동차 보유 한도에 대한 지방생활보장
위원회 심의, 재산범위 특례, 근로능력 판정 등을 포함한 관할 읍·면·동 주민센터/시·군·구청의 공적
조사(사회보장정보시스템)를 거쳐 최종 확정됩니다. 신청 전 반드시 관할 행정복지센터 또는
보건복지상담센터(129)에 문의하시기 바랍니다.

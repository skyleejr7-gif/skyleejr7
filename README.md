# 국민기초생활수급자·차상위계층·한부모가족 판정 프로그램

소득·재산·금융재산·자동차 정보를 입력하면 **소득인정액**을 계산하고,
생계·의료·주거·교육급여(국민기초생활수급자), 차상위계층, 한부모가족(일반/청소년) 선정기준
충족 여부를 판정하는 웹 기반 계산기입니다.

## 사용 방법

별도 설치나 서버 없이, `index.html` 파일을 웹 브라우저(Chrome, Edge 등)로 열기만 하면 됩니다.

```
index.html 더블클릭 → 브라우저에서 실행
```

## 주요 기능

- **가구 정보**: 가구원 수, 거주 지역(서울/경기/광역·세종·창원/그 외)에 따른 재산 기본공제액 자동 반영
- **소득 산정**: 가구원별 근로소득 + 공제 특례(기본 30%, 대학생, 만19~34세 청년/24세 이하 청소년한부모)
  자동 계산, 사업·재산·이전소득, 가구특성별 지출비용(의료비 등) 반영
- **재산의 소득환산액**: 주거용(1.04%)·일반(4.17%)·금융(6.26%) 재산별 환산율, 부채·기본공제액
  순차 차감(부채: 일반→주거용→금융, 기본공제: 주거용→일반→금융)
- **자동차 재산**: 차량별 배기량·가액·연식·용도를 입력하면 원칙(100%)/완화(4.17%, 2000cc 미만·500만원
  미만 또는 10년 이상 노후차량)/제외(생업용 1대, 중증장애인·국가유공자 상이1~3급 이동수단 1대,
  다자녀 특례) 규정을 자동 적용
- **판정표**: 생계급여(32%)·의료급여(40%)·주거급여(48%)·교육급여(50%)·차상위계층(50%)·
  한부모가족/조손가족(63%)·청소년한부모/조손가족 완화기준(65%)을 한 번에 비교
- **기준값 설정**: 기준 중위소득, 선정기준 비율, 지역별 재산공제액, 소득환산율 등을 화면에서
  직접 수정 가능 (매년 8월경 보건복지부가 익년도 기준 중위소득을 새로 고시하므로, 연도가
  바뀌면 이 값들만 갱신하면 계속 사용할 수 있습니다)

## 데이터 출처 (2026년 기준 기본값)

- 보건복지부, 「2026년도 기준 중위소득 및 생계·의료·주거·교육급여 선정기준」 고시
- 보건복지부, 2026년 국민기초생활보장사업안내 (재산 기본공제액, 소득환산율, 자동차 재산 기준)
- 여성가족부, 2026년 한부모가족지원사업안내 (한부모가족·청소년한부모·조손가족 선정기준)
- 찾기쉬운 생활법령정보(easylaw.go.kr)

## 유의사항

이 프로그램은 대표적인 산식을 단순화하여 반영한 **참고·추정용 도구**입니다. 실제 수급자
결정은 부양의무자 조사(의료급여), 재산 세부 항목 확인, 특례 적용 여부 등을 포함한 관할
읍·면·동 주민센터/시·군·구청의 공적 조사를 거쳐 최종 확정됩니다. 신청 전 반드시 관할
행정복지센터 또는 보건복지상담센터(129)에 문의하시기 바랍니다.
